# Data – ClearPath

Public data only. No real company data and no real personal data.

| File | Source | What it contains |
|---|---|---|
| `life_events_survey_2023_report.pdf` | Destatis – Lebenslagenbefragung 2023, Bürgerinnen und Bürger | Original official report (latest published edition) |
| `life_events_satisfaction_2023.csv` | Table 1 of the report above | 23 life situations × 17 factors + average; satisfaction from –2 (very unhappy) to +2 (very happy). Empty cells = "/" in the report (too few answers). |
| `foreign_population_by_citizenship_2018_2025.csv` | Destatis – Foreign population by selected citizenships and years (Central Register of Foreigners), https://www.destatis.de/EN/Themes/Society-Environment/Population/Migration-Integration/Tables/foreigner-citizenship-time-serie.html | Foreign residents by citizenship, 2018–2025, as at 31 December. Numbers rounded to multiples of 5 by Destatis. |

All values were checked by hand against the original sources.
